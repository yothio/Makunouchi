# UI作成
## 管理画面
- トップページ
- 質問解答一覧
- 質問解答の作成・編集
- 開催回作成
- 開催回詳細


### トップページ
- 表示
  - 質問解答の数
  - 質問解答の一覧への遷移ボタン
  - 開催回のタイトル
  - 開催回作成のボタン
- 入力
- 操作
  - 質問解答一覧への遷移ボタン
  - 開催回作成ボタン

### 質問解答一覧
- 表示
  - 質問と解答の一覧が表示
  - 新規作成ボタン
- 入力
- 操作
  - 質問と解答をクリック
  - 新規作成をクリック
  - トップページへ戻るボタン

### 質問解答の作成・編集
- 表示
  - 質問のタイトルラベルと入力欄
  - 設定済み画像のプレビュー
  - 選択肢のラベルと入力欄
  - 正解の選択欄
  - 保存ボタン
- 入力
  - 質問のタイトル
  - 画像アップロードボタン
  - 選択肢AからDの入力
  - 正解の選択肢の設定
- 操作
  - 正解の選択肢の設定
  - アップロードボタン
  - 保存ボタン

### 開催回作成
- 表示
  - 開催回名
- 入力
  - 開催回名入力
- 操作
  - 作成ボタン
  - topへ戻るボタン



### 開催回詳細
- 表示
  - 幹事のID,PASS
  - 作成したタイミングの質問解答
- 入力
- 操作
  - topへ戻るボタン
